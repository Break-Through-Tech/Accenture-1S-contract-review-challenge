# Dataset Information

## Contract Understanding Atticus Dataset (CUAD)
This project uses the Contract Understanding Atticus Dataset (CUAD), a publicly available dataset of commercial contracts.

### Source
Official Repository:
https://github.com/TheAtticusProject/cuad

### Download Instructions
Students should download the latest dataset directly from the official CUAD repository and follow the instructions provided by the dataset maintainers.

### Notes
- The full dataset is not stored in this repository.
- Teams should use the official version maintained by The Atticus Project.
- Initial project scope should focus on the 10 highest-impact clause categories, with additional categories treated as stretch goals.
